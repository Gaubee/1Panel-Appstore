# GaubeeOS 内核 - 桌面 OS 式站点内核

可自部署的「桌面操作系统」式站点内核：内置 Rust 订阅引擎（GitHub 仓库 → 定时同步 → 本地缓存）、应用系统、终端、代码编辑器、Git 客户端与全文搜索。**不内置任何内容**——安装后在设置中订阅任意 GitHub markdown 仓库，即可拥有自己的站点。

## 使用方式

1. 安装后访问 `http://<主机IP>:8090`（端口可在安装时修改）
2. 进入「设置 → 内容源 → 添加内容源」：填写 GitHub owner/repo、内容类型（文章/说说）、路径匹配 glob（如 `src/content/articles/**/*.md`）
3. 「测试连接」预览命中文件数 → 「订阅并同步」→ 文章/说说应用即刻出数
4. 可订阅多个源（文章/说说各多个）；slug 前缀用于多源 URL 防冲突

## 说明

- **有状态应用**：订阅配置与内容缓存落在应用目录 `./data`（升级/重建不丢）
- **同步引擎**：Rust 实现，分支 sha 未变自动跳过；正文走 raw CDN（不占 API 限额）；每源可配频率（15m~24h）
- **GitHub Token（可选）**：匿名同步限 60 次 API/小时（多源高频同步建议配置）；token 只需只读 public repo 权限
- **OAuth 登录（可选）**：编辑器写入/提交需要自建 Cloudflare Worker（见上游 README）；未配置时为纯只读部署，登录入口自动隐藏
- 与「GaubeeOS」（博主 gaubee.com 单体镜像）的区别：本应用是通用内核，内容全部来自订阅
- 仅提供 `linux/amd64` 架构镜像
